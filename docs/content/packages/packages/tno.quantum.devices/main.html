devices

1.0.1

This package can be used to connect to backends from various quantum providers.

Currently, the supported quantum providers are:

  • IBM Quantum Platform

  • Azure Quantum

Besides external quantum providers, this package also provides the functionality to instantiate the default PennyLane devices.

Installation

Install the base package using pip:

pip install tno.quantum.devices

Provider-specific dependencies can be installed via extras:

pip install tno.quantum.devices[ibm]    # for IBM Quantum backends
pip install tno.quantum.devices[azure]   # for Azure Quantum backends

Bases: BaseConfig[Device]

Configuration class for creating PennyLane Device instances.

Supported devices can be obtained by calling supported_items().

Example

>>> from tno.quantum.devices import DeviceConfig
>>>
>>> # List available PennyLane devices
>>> sorted(DeviceConfig.supported_items())
[..., 'default.gaussian', 'default.mixed', 'default.qubit', ...]
>>>
>>> # Instantiate PennyLane device
>>> config = DeviceConfig("default.qubit", options={"wires": 5})
>>> type(config.get_instance())
<class 'pennylane.devices.default_qubit.DefaultQubit'>
